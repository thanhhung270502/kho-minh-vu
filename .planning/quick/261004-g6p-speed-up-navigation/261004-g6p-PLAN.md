# Quick 261004-g6p: Tăng tốc chuyển trang

## Bối cảnh (đo trên production 04/10)

- Bấm menu → đổi trang mất 2,5–3,7s. Vercel chạy ở `hkg1`, Supabase `rnpq` ở `ap-southeast-2` (Sydney):
  mỗi lượt gọi Supabase từ server ~200–700ms.
- Gói RSC `/nhap-kho`: khung về lúc 0,6s, nội dung trang lúc 2,7s — chờ `requirePermission`
  (3 lượt gọi NỐI TIẾP: `getUser` → `nguoi_dung` → `quyen_cua_toi`).
- Tải đầy đủ: layout và page mỗi bên tự gọi `getCurrentUser` → 6 lượt + 1 ở proxy.
- Không có `loading.tsx` → bấm menu không có phản hồi gì cho tới khi server trả xong.
- Đổi region do người dùng tự làm, ngoài phạm vi task. Giữ `getUser()` ở proxy (quy tắc CLAUDE.md).

## Task 1 — `getCurrentUser` dùng chung + song song

- files: `src/features/auth/api/current-user.server.ts`
- action: bọc `getCurrentUser` bằng `cache()` của React (dedupe trong MỘT request —
  không rò rỉ giữa người dùng). Đọc `nguoi_dung` và RPC `quyen_cua_toi` bằng `Promise.all`
  (RPC không phụ thuộc kết quả bảng; RLS tự giới hạn theo `auth.uid()`).
- verify: `npm run check`
- done: tải đầy đủ còn 1 lượt `getUser` + 1 lượt song song trong render; chuyển trang
  client còn `getUser` + 1 lượt song song (từ 3 nối tiếp).

## Task 2 — Khung chờ khi chuyển trang

- files: `src/app/(app)/loading.tsx`
- action: Server Component không import antd (bẫy 1) — render khung xương bằng Tailwind
  (tiêu đề + mô tả + thanh công cụ + các dòng bảng), `animate-pulse`, có `aria-busy`.
  Nằm dưới `AppShell` nên menu vẫn giữ nguyên, chỉ vùng nội dung đổi sang khung chờ.
- verify: `npm run check`; mở trình duyệt local, bấm qua lại menu, xem console.
- done: bấm menu là thấy khung chờ ngay, không còn đứng hình.
