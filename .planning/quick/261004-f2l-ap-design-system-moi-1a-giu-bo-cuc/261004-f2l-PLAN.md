# Quick 261004-f2l — Áp design system mới (tham khảo "Kho Minh Vu 1A"), giữ nguyên bố cục

## Mục tiêu

Đổi "lớp da" toàn app sang design system đơn sắc của bản design 1A
(https://claude.ai/artifact/QaWzNG6HWaQUqbHjh6mfyu) — **không** đổi bố cục,
không đổi logic/dữ liệu/quyền. Design chỉ là tham khảo: lấy token, font, cách
trình bày trạng thái; KHÔNG dựng lại màn theo layout của design.

## Token trích từ design

| Vai trò | Giá trị |
|---|---|
| Primary / chữ chính / nav active | `#0A0A0A` |
| Nền trang | `#FAFAFA` |
| Nền thẻ | `#FFFFFF` |
| Viền thẻ / kẻ bảng | `#EBEBEB` (kẻ dòng `#F3F3F3`), viền input `#E5E5E5` |
| Chữ phụ | `#737373`, nhạt hơn `#8C8C8C`, placeholder `#A3A3A3` |
| Chữ nav thường | `#525252` |
| Header bảng | nền `#FCFCFC`, chữ hoa 11–11.5px, `letter-spacing .04em`, màu `#8C8C8C` |
| Hover dòng / nền tổng | `#FAFAFA` |
| Cảnh báo (nhập liệu, dưới ĐM) | `oklch(0.68 0.16 60)` ≈ `#E08A1E`; chữ trên nền nhạt `oklch(0.48 0.13 55)`, nền `oklch(0.96 0.04 70)` |
| Nguy hiểm (tồn âm) | `oklch(0.58 0.2 27)` ≈ `#D9352B` |
| Bo góc | thẻ 12, nút 9, input 8, chip 99 |
| Đổ bóng thẻ | không — chỉ viền 1px |
| Font | Be Vietnam Pro (400/500/600/700); JetBrains Mono cho số phiếu & mã hàng |

## Tasks

### Task 1 — Token nền tảng
- **files:** `src/providers/antd-theme.ts`, `src/app/globals.css`, `src/app/layout.tsx`, `src/shared/lib/design-tokens.ts`
- **action:**
  - `antd-theme.ts`: viết lại token theo bảng trên (primary đen, border `#EBEBEB`/`#E5E5E5`, Table header `#FCFCFC` chữ `#8C8C8C`, bỏ shadow nút/input xanh, Card không bóng, Tag nền `#F3F3F3` không viền, Modal bo 16).
  - `globals.css`: giữ TÊN biến (tránh sửa hàng chục file), đổi GIÁ TRỊ: thang `brand-*` → thang trung tính tối (500 = `#0A0A0A`, 25/50 = nền chọn xám nhạt); `trung-tinh-*` → thang neutral của design; `--shadow-the: none` + thêm viền cho thẻ qua `ListLayout`; `--font-mono` = JetBrains Mono. Thêm style header bảng chữ hoa (`.ant-table-thead > tr > th`) trong `@layer components`.
  - `layout.tsx`: `next/font/google` Be Vietnam Pro + JetBrains Mono (không phải thư viện mới).
  - `design-tokens.ts`: CHART_COLORS đơn sắc + cam/đỏ nhấn; SEMANTIC_COLORS theo bảng.
- **verify:** `npm run typecheck`
- **done:** nút primary đen, bảng header xám chữ hoa, font Be Vietnam Pro.

### Task 2 — Vỏ app: thanh điều hướng, tài khoản, thẻ
- **files:** `src/shared/components/top-nav.tsx`, `nav-pill.tsx`, `bottom-tab-bar.tsx`, `account-menu.tsx`, `list-layout.tsx`, `page-header.tsx`
- **action:** giữ nguyên cấu trúc/overflow; đổi pill xanh gradient → nền trắng, chữ `#525252`, mục active nền `#0A0A0A` chữ trắng bo 8; logo thêm ô "MV" đen 26px; tài khoản: avatar xám + tên đậm + vai trò chữ phụ (bỏ Tag); thẻ lọc/bảng: viền `#EBEBEB` thay bóng; tiêu đề trang 26px/600 letter-spacing -.025em.
- **verify:** `npm run check`
- **done:** header trắng nav đen-trắng như design, bố cục y như cũ.

### Task 3 — Trạng thái chấm màu + mono cho số phiếu
- **files:** `src/shared/components/status-dot.tsx` (mới), `src/features/documents/types.ts`, `src/features/sales-order/lib/order-status.ts`, `src/features/stocktake/lib/session-status.ts`, các chỗ đang `<Tag color={…STATUS_COLORS…}>`
- **action:** component `StatusDot` (chấm 7px + chữ 13px/500, `strike` cho Đã hủy). Đổi map màu trạng thái sang tone `warning | done | muted | danger | info`. Thay Tag trạng thái chứng từ/đơn/phiên kiểm kê bằng `StatusDot`. Cột số phiếu dùng `font-mono`.
- **verify:** `npm run check` + mở `/nhap-kho`, `/xuat-kho`, `/` trên trình duyệt, xem console.
- **done:** trạng thái hiển thị chấm + chữ; Đã hủy xám gạch ngang.
