    - Hằng: `ROOT_FOLDER_NAME = 'Kho Minh Vu - Anh'`; `ALLOWED_FOLDERS = ['san-pham/goc', 'san-pham/thumb']` (nhánh `chung-tu/...` để phase sau, D-08);
      `FILE_NAME_PATTERN = /^[A-Za-z0-9._-]{1,120}\.webp$/`; `MAX_BASE64_LENGTH = 2000000`.
    - `function json_(obj)` → `ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON)`.
    - `function fail_(error, message)` → `json_({ ok: false, error: error, message: message })`.
    - `function doGet(e)` → `fail_('bad_request', 'Chỉ nhận POST')` (mở URL /exec trên trình duyệt không lộ gì).
    - `function doPost(e)`: parse `e.postData.contents` trong try/catch (lỗi → `bad_request`); `secret` phải là chuỗi và bằng
      `PropertiesService.getScriptProperties().getProperty('SECRET')`; SECRET chưa đặt hoặc lệch → `fail_('forbidden', 'Sai hoặc thiếu secret')`.
      Phân nhánh `action`: `put` → `put_(body)`, `get` → `get_(body)`, `remove` → `remove_(body)`, khác → `bad_request`. Bọc toàn bộ trong
      try/catch: lỗi lạ → `fail_('internal', String(err && err.message || err))` (không trả stack).
    - `function put_(body)`: kiểm `ALLOWED_FOLDERS.indexOf(body.folder) >= 0`, `FILE_NAME_PATTERN.test(body.fileName)`, `body.mimeType === 'image/webp'`,
      `typeof body.base64Data === 'string' && body.base64Data.length > 0 && body.base64Data.length <= MAX_BASE64_LENGTH` — sai → `bad_request` kèm lý do.
      `var blob = Utilities.newBlob(Utilities.base64Decode(body.base64Data), 'image/webp', body.fileName);`
      `var file = getFolder_(body.folder).createFile(blob);` → `json_({ ok: true, fileId: file.getId() })`. KHÔNG gọi `setSharing` (file private).
    - `function get_(body)`: `fileId` chuỗi khác rỗng; `DriveApp.getFileById` trong try/catch → lỗi → `not_found`; `file.isTrashed()` → `not_found`;
      trả `{ ok: true, mimeType: file.getMimeType(), base64Data: Utilities.base64Encode(file.getBlob().getBytes()) }`.
    - `function remove_(body)`: như get để tìm file (không thấy → `not_found`); `if (!file.isTrashed()) file.setTrashed(true);` → `{ ok: true }` (idempotent).
    - `function getRootFolder_()`: đọc property `ROOT_FOLDER_ID` (người dùng có thể tự đặt); nếu có và `DriveApp.getFolderById` mở được + chưa trashed → dùng;
      không thì tạo `DriveApp.createFolder(ROOT_FOLDER_NAME)` và lưu `ROOT_FOLDER_ID`.
    - `function getFolder_(path)`: key cache `'FOLDER_' + path`; đọc property, mở được và chưa trashed → trả. Không thì
      `var lock = LockService.getScriptLock(); lock.waitLock(10000);` trong try/finally `lock.releaseLock()`: đọc lại property (request khác có thể vừa tạo),
      nếu vẫn không có thì đi từng đoạn của `path.split('/')` từ root: `getFoldersByName(seg)` có thì dùng `next()`, không thì `createFolder(seg)`; lưu id vào property.
    - `function kiemTraThietLap()`: chạy tay trong trình soạn thảo lần đầu để Google hỏi quyền Drive; gọi `getFolder_` cho cả hai folder, `Logger.log`
      URL folder gốc và báo SECRET đã đặt hay chưa (không in giá trị SECRET).
    Không dùng `UrlFetchApp` (không gọi ra ngoài). Không dùng thư viện ngoài.
