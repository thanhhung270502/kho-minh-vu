Thêm vào cuối `supabase/migrations/0005_san_pham.sql`:

```sql
-- Tìm đồng thời theo mã và tên, gõ không dấu vẫn ra kết quả có dấu.
-- f_unaccent phải là IMMUTABLE dạng 2 tham số (xem 0001) — nếu không Postgres
-- từ chối dựng index với lỗi "functions in index expression must be marked IMMUTABLE".
create index idx_san_pham_tim_kiem
  on public.san_pham
  using gin (
    public.f_unaccent(coalesce(ma_hang,'') || ' ' || coalesce(ten_hang,''))
    extensions.gin_trgm_ops
  );
```

`coalesce(...,'')` ở cả hai vế là bắt buộc: `ten_hang` là NOT NULL nhưng `ma_hang || ' ' || null`
sẽ trả NULL nếu sau này có cột nullable tham gia — để sẵn cho an toàn.

Sau khi `npm run db:reset`, xác nhận index được dùng thật:

```sql
explain analyze
select * from public.san_pham
where public.f_unaccent(coalesce(ma_hang,'') || ' ' || coalesce(ten_hang,''))
      % public.f_unaccent('bac dan');
```

Kết quả phải có `Bitmap Index Scan on idx_san_pham_tim_kiem`. Nếu thấy `Seq Scan`, nguyên
nhân thường là gọi `f_unaccent` khác biểu thức index (sai thứ tự cột, thiếu `coalesce`,
thiếu dấu cách) — biểu thức trong WHERE phải khớp **từng ký tự** với biểu thức index.

Ghi câu EXPLAIN này vào `supabase/README.md` mục "Kiểm tra index tìm kiếm" để plan 12 dùng lại.
