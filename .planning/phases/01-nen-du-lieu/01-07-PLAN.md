```sql
create or replace function public.tim_san_pham(
  p_tu_khoa text,
  p_gioi_han int default 20
)
returns setof public.san_pham
language sql
stable
as $$
  select sp.*
  from public.san_pham sp
  where sp.dang_kinh_doanh
    and public.f_unaccent(coalesce(sp.ma_hang,'') || ' ' || coalesce(sp.ten_hang,''))
        % public.f_unaccent(p_tu_khoa)
  order by
    sp.lan_phat_sinh_cuoi desc nulls last,
    similarity(
      public.f_unaccent(coalesce(sp.ma_hang,'') || ' ' || coalesce(sp.ten_hang,'')),
      public.f_unaccent(p_tu_khoa)
    ) desc
  limit p_gioi_han;
$$;

grant execute on function public.tim_san_pham(text, int) to authenticated;
```

Điểm bắt buộc:

- **Biểu thức trong WHERE phải khớp TỪNG KÝ TỰ với biểu thức index** ở migration 0005:
  `public.f_unaccent(coalesce(ma_hang,'') || ' ' || coalesce(ten_hang,''))`. Sai thứ tự cột,
  thiếu `coalesce`, hay thiếu dấu cách đều làm Postgres không nhận ra và chuyển sang `Seq Scan`.
- **`%` là toán tử trigram similarity** (ngưỡng mặc định `pg_trgm.similarity_threshold = 0.3`),
  dùng được index GIN. Không thay bằng `ILIKE '%...%'` — ILIKE không dùng được index này.
- **`lan_phat_sinh_cuoi desc nulls last` đứng TRƯỚC `similarity`** trong ORDER BY: mã vừa
  phát sinh quan trọng hơn mã khớp sát chữ. `nulls last` đẩy 2.043 mã chưa từng luân chuyển
  xuống cuối.
- **`security invoker` (mặc định)** — cố ý. Hàm này phải tôn trọng RLS trên `san_pham`, khác
  với `ghi_so_chung_tu` cần `security definer` để ghi vào bảng client không có quyền.
- Không cần index B-tree riêng cho `lan_phat_sinh_cuoi`: ORDER BY chạy sau khi `%` đã thu hẹp
  tập kết quả xuống vài chục dòng trong 3.266.

Kiểm sau khi reset (cần có dữ liệu mẫu — nếu chưa có thì kiểm lại ở plan 12):
```sql
explain analyze select * from public.tim_san_pham('bac dan');
```
Phải thấy `Bitmap Index Scan on idx_san_pham_tim_kiem`, không được thấy `Seq Scan on san_pham`.

-- Sổ cái trả lời "vì sao tồn là con số này", bảng tồn trả lời "tồn là bao nhiêu".
-- Trigger giữ hai bảng khớp nhau; view này là lưới an toàn phát hiện khi chúng lệch.
create or replace view public.v_doi_chieu_ton as
select
  coalesce(tk.kho_id, mv.kho_id)             as kho_id,
  coalesce(tk.san_pham_id, mv.san_pham_id)   as san_pham_id,
  coalesce(tk.so_luong, 0)                   as ton_theo_bang,
  coalesce(mv.tong_movement, 0)              as ton_theo_so_cai,
  coalesce(tk.so_luong, 0) - coalesce(mv.tong_movement, 0) as chenh_lech
from public.ton_kho tk
full outer join (
  select kho_id, san_pham_id, sum(so_luong) as tong_movement
  from public.kho_movement
  group by kho_id, san_pham_id
) mv on mv.kho_id = tk.kho_id and mv.san_pham_id = tk.san_pham_id;

create or replace function public.doi_chieu_ton()
returns table (
  kho_id uuid,
  san_pham_id uuid,
  ton_theo_bang numeric(18,4),
  ton_theo_so_cai numeric(18,4),
  chenh_lech numeric(18,4)
)
language sql
stable
security definer
set search_path = ''
as $$
  select v.kho_id, v.san_pham_id, v.ton_theo_bang, v.ton_theo_so_cai, v.chenh_lech
  from public.v_doi_chieu_ton v
  where v.chenh_lech <> 0
  order by abs(v.chenh_lech) desc;
$$;

grant execute on function public.doi_chieu_ton() to authenticated;
```

`full outer join` là cố ý: bắt được cả hai chiều lệch — dòng có trong `ton_kho` mà không có
movement nào, và movement có mà `ton_kho` thiếu dòng.

Hàm trả rỗng khi mọi thứ khớp. Đó là kết quả mong đợi khi chạy hằng đêm.

-- pg_cron trên Supabase local (Docker CLI stack) KHÔNG đáng tin: nhiều issue mở về
-- database-name mismatch và cấp quyền (supabase/cli#158, #1591, chưa có fix tính đến 09/2026).
-- Bọc toàn bộ trong DO ... EXCEPTION để `npm run db:reset` không bao giờ hỏng ở máy dev.
-- Trên cloud, nếu khối này không chạy được thì đăng ký cron qua Dashboard (theo D-02).
do $$
begin
  -- pg_cron KHÔNG relocatable: nó luôn tạo object trong schema tên `cron`.
  -- Viết `with schema extensions` sẽ lỗi, và `extensions.cron.schedule(...)` không
  -- phải tên hàm hợp lệ — dùng vậy thì khối này luôn rơi vào nhánh exception và
  -- cron không bao giờ đăng ký được, kể cả ở môi trường pg_cron chạy tốt.
  create extension if not exists pg_cron;

  perform cron.schedule(
    'doi-chieu-ton-hang-dem',
    '0 1 * * *',
    $cron$ select public.doi_chieu_ton(); $cron$
  );

  raise notice 'Đã đăng ký job doi-chieu-ton-hang-dem';
exception when others then
  raise notice 'Bỏ qua đăng ký pg_cron (%). Đăng ký thủ công qua Dashboard khi lên cloud.', sqlerrm;
end $$;
```

  (`select public.doi_chieu_ton();`). Plan 12 test phần này.
- Đăng ký `cron.schedule` — rủi ro cao, có thể không chạy ở local. KHÔNG coi là tiêu chí
