Tạo `scripts/import-kiotviet/doc-file.ts` dùng `exceljs` (đã có trong package.json).

Export hàm `docSheet(duongDan: string): Promise<DongTho[]>` với `DongTho = { soDong: number;
o: Record<string, string | number | null> }`.

**Ba bẫy của file KiotViet export phải xử lý, không phải phòng xa:**

1. **Cột số định dạng Text.** `exceljs` trả `cell.value` là `string` thay vì `number`. Viết
   helper `doSo(v: unknown): number | null` — nhận cả string lẫn number, bỏ dấu phân cách
   nghìn (`.` và `,` theo kiểu Việt Nam), trả `null` nếu không parse được. **Không tin
   `typeof v === 'number'`.**

2. **Dòng tổng và dòng trống ở cuối sheet.** Bỏ dòng mà mọi ô đều rỗng, và bỏ dòng mà ô đầu
   tiên chứa (không phân biệt hoa thường, đã bỏ dấu) một trong: `tong`, `tong cong`, `cong`.

3. **Ô rich text và formula.** `cell.value` có thể là object `{ richText: [...] }` hoặc
   `{ formula, result }`. Viết helper `doChuoi(v: unknown): string | null` xử lý cả hai,
   trả về text phẳng đã `trim()`.

Thêm:
- Chuẩn hóa tên cột header: bỏ dấu, lowercase, thay khoảng trắng bằng `_` — để code không
  phụ thuộc việc KiotViet viết "Mã hàng" hay "Mã Hàng".
- Giữ **nguyên dòng gốc** dưới dạng object để ghi vào cột `du_lieu_goc jsonb` ở plan 15.
- `soDong` là số dòng thật trong file (tính cả header), để báo cáo lỗi chỉ đúng chỗ người
  dùng mở Excel xem được.

Nếu file không tồn tại, ném lỗi có hướng xử lý: nói rõ tên file cần đặt và đường dẫn
`data/kiotviet/`, trỏ tới `data/kiotviet/README.md`.

type KetQuaKiemTra<T> = {

Tạo `scripts/import-kiotviet/index.ts`.

CLI: `npm run import:kiotviet -- [--dry-run] [--file <ten>] [--mau]`

- `--dry-run` — đọc, kiểm, in báo cáo, **không kết nối ghi database**. Đây là mặc định an
  toàn: nếu thiếu cả hai cờ thì **chạy như --dry-run** và in nhắc rằng phải thêm `--ghi` để
  nạp thật. Không để người dùng vô tình ghi đè dữ liệu bằng một lệnh gõ thiếu.
- `--file <ten>` — chỉ xử lý một file, để soi nhanh khi sửa lỗi.
- `--mau` — chạy trên dữ liệu mẫu tự sinh trong `scripts/import-kiotviet/du-lieu-mau/`
  thay vì `data/kiotviet/`. Cho phép viết và test script trước khi có file thật.

Tạo bốn file mẫu nhỏ (10-20 dòng mỗi file) trong `scripts/import-kiotviet/du-lieu-mau/`, cố
ý nhét sẵn các ca lỗi: một dòng thiếu mã hàng, một mã trùng, một ô số định dạng text, một
dòng "TỔNG CỘNG" ở cuối, một ĐVT lạ. Đây là bộ test của chính script.
